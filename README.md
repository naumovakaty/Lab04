## Диспетчер задач показывает, что на моем устройстве ядер -2, логических процессоров -2, базовая скорость - 1,70 ГГц.
значение Environment.ProcessorCount необходимо сравнивать с количеством логических процессоров, потому что эта функция возвращает именно то число вычислительных единиц, которое видит операционная система. Операционная система распределяет потоки программы по логическим процессорам, для полной загрузки CPU (до 100%) количество создаваемых потоков должно равняться количеству логических процессоров. сравнение с физическими ядрами дало бы неверный результат, и процессор остался бы недогруженным.
##Вывод о загрузке CPU. Что происходит: 1. Рост нагрузки. Чем больше потоков я запускаю одновременно, тем выше поднимается график загрузки ЦП. 2. Упираемся в предел. Мой процессор (Intel Pentium 3556U) имеет 2 ядра и 2 логических процессора. Когда запустила 1 поток , загрузка ЦП поднимается примерно до 50%. Когда 2 потока, они занимают оба логических процессора, загрузка подскакивает до 100%.Увеличение числа потоков повышает загрузку CPU до тех пор, пока она не достигнет 100%. Дальнейшее увеличение потоков только создает дополнительную нагрузку на систему, но не ускоряет вычисления. Число Environment.ProcessorCount  показывает, сколько потоков имеет смысл запускать для максимальной эффективности производительности.

у моего процессора количество физических ядер и логических процессоров совпадает = 2.Разберем пример из методички с помощью сети интернет. Физическое ядро выполняет вычисления. В примере их 4. Логический процессор - это то, как операционная система видит вычислительные блоки. Благодаря технологии Hyper-Threading одно физическое ядро притворяется двумя. Оно выделяет два "виртуальных потока" для решения задач. В примере с 4 ядрами и 8 логическими процессорами Environment.ProcessorCount покажет цифру 8. Чтобы загрузить на 100% , нужно будет запустить 8 потоков, по одному на каждый логический процессор.

В покое частота была низкой, так как процессор экономил энергию. Во время нагрузки частота выросла до базовой, так как процессору пришлось работать на полную мощность.
## Контрольные вопросы
1. Environment.ProcessorCount показывает количество логических процессоров, доступных операционной системе и текущему процессору для выполнения задач. это число включает в себя физические ядра и виртуальные потоки.
2. физическое ядро - реальный аппаратный вычислительный блок в процессоре. Логический процессор - это программная надстройка (поток), которая позволяет операционной системе отправлять задачи на физическое ядро.
3. Каждый поток - это отдельная цепочка задач. если программа однопоточная, она использует только один логический процессор. При создании нескольких потоков операционная система распределяет их по разным логическим процессорам, вовлекая в работу больше аппаратных ресурсов, из-за чего общая нагрузка CPU растет.
4. После некоторого количества потоков загрузка не обязательно продолжает расти, потому что загрузка процессора достигает своего физического предела 100%, когда все логические процессоры заняты.Дальнейшее увеличение количества потоков не заставит процессор работать быстрее. Вместо этого система начнет тратить ресурсы на "переключение контекста", что может даже замедлить выполнение программы. 
5. Современные процессоры используют техгологии динамического управления энергопотреблением. При простое частота снижается для экономии энергии и уменьшения нагрева. Под нагружкой частота повышается для масимальной производительности. Также частота может снижаться при сильном нагреве, тобы защитить процессор от перегрева.
